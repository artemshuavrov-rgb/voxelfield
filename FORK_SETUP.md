# Работа с форком Voxelfield

Этот репозиторий — форк [qhdwight/voxelfield](https://github.com/qhdwight/voxelfield).

## Запуск проекта

1. Клонируйте репозиторий вместе с подмодулем:

   ```sh
   git clone --recurse-submodules https://github.com/artemshuavrov-rgb/voxelfield.git
   ```

   Если репозиторий уже клонирован, выполните `git submodule update --init --recursive`.
2. Установите **Unity 6000.3.15f1** — версия записана в `ProjectSettings/ProjectVersion.txt`.
3. Откройте папку репозитория как существующий проект в Unity Hub.
4. Откройте сцену `Assets/Scenes/Base.unity` и нажмите **Play** в редакторе. На главном экране выберите **START SOLO DEMO**. Персонаж сразу появится на карте Castle с винтовкой и полным набором предметов.
5. Клавиши **WASD** — движение, **мышь** — обзор и стрельба, **1–0** — выбор предметов, **Esc** — пауза. Пули, кирка и взрывчатка разрушают все четыре типа воксельного материала. При разрушении появляются цветные осколки с физикой и искры. Кнопка **RESET ARENA** в паузе начинает новую сессию.
6. После изменений в исходниках дождитесь окончания компиляции Unity и снова нажмите **Play**. Отдельная сборка для проверки обновлений не требуется.

## Репозитории Git

- `origin` — этот форк;
- `upstream` — исходный проект.

Чтобы добавить `upstream` в новой локальной копии:

```sh
git remote add upstream https://github.com/qhdwight/voxelfield.git
```
